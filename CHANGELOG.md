# История выпусков

## 0.1.0 — 2026-11-12

Первый публичный предварительный выпуск.

### Добавлено

- SOCKS5 CONNECT через канал `rdpproxy.v1` с режимами ServerProxy и ClientProxy.
- Приложения клиента и сервера для Windows x64 с управлением через трей.
- Регистрация COM для x64 и x86 RDP-клиентов в профиле текущего пользователя.
- Пароли, создаваемые автоматически или загружаемые из отдельного auth-файла.
- Изоляция каналов нескольких RDP-серверов в ServerProxy.
- Локальный статус, диагностические журналы и необязательные замеры времени.
- PowerShell-скрипты запуска, регистрации, управления credentials и скачивания.
- Полный и компактный архивы, сборка и упаковка в GitHub Actions.

### Ограничения предварительного выпуска

- Реальная пользовательская RDP-сессия после изменений интерфейса трея
  не проверена; успешная CI-сборка не заменяет такую проверку.
- Целевая платформа — .NET 8 Desktop, поддержка которой закончилась
  2026-11-10. Переход на .NET 10 LTS планируется отдельно до стабильного выпуска.
- Цифровая подпись исполняемых файлов не настроена.
